# Документация mcprig

mcprig — один статический бинарник, который ставит много MCP-серверов за одну
точку: клиент видит пять мета-инструментов вместо всех инструментов всех
серверов, а каждый *набор* живёт отдельным процессом со своим портом и ключом.
Тот же бинарник несёт реестр, супервизию и веб-панель.

Всё ниже написано по выпущенному бинарнику. Числа, имена флагов и тексты ошибок
настоящие; если страница и бинарник расходятся — прав бинарник, заведите issue.

## Три пути

**Поставить.** Взять релизный архив или образ, поставить юнит systemd, один раз
прогнать `mcprig doctor`: он проверяет конфиг, наборы, ключи, секреты и занятые
порты одним проходом.
→ [install.md](install.md), затем [cli.md#doctor](cli.md#doctor).

**Настроить и подключить.** Один `servers.json` описывает набор; его же правит
панель. Фрагмент для клиента печатает `mcprig init`, ключ набора передаётся
клиенту — и клиент видит мета-инструменты.
→ [configuration.md](configuration.md) → [cli.md#init](cli.md#init) →
[meta-tools.md](meta-tools.md).

**Разрабатывать.** Сборка, тестовые ворота (`-p 1` не опция), живой стенд на
настоящих серверах, выпуск релиза.
→ [dev/development.md](dev/development.md) → [dev/release.md](dev/release.md).
