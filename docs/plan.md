# План переписывания на Go

**Вход:** `docs/reference/ts-manager-contract.md` (поведение + 10 обязательных
исправлений), решение `docs/decisions/0001-two-repos.md`.
**Приоритет владельца:** вес и холодный старт. Один бинарник на всё.
**Стек:** Go 1.27, `github.com/modelcontextprotocol/go-sdk` v1.8.0
(протокол по умолчанию `2026-07-28`), stdlib для HTTP и шаблонов, без внешних
веб-зависимостей.

## Ворота

Одна команда на весь проект:

```bash
E2E_BASE=http://127.0.0.1:9091 go test ./e2e -v
```

Плюс `go build ./... && go vet ./... && go test ./...` на каждом коммите.
Этап считается принятым, только когда e2e зелёный в strict-режиме.

## Дашборд

Отдельный трек, начинается после этапа 4 (нужны живые данные: статусы наборов,
health, вызовы). Экран показывает то, чего сейчас нет ни в одной вкладке:
состояние всех наборов разом, здоровье серверов, поток вызовов с задержками,
незаполненные переменные. Дизайн требует приёмки до реализации — по правилам
проекта UI не пишется без согласованного макета.

## Что решаем заранее

- **Формат `servers.json`:** оставляем совместимым с lazy-mcp (это контракт
  между менеджером и набором). Новые поля — только опциональные.
- **Порты:** 9100–9199 как диапазон публикации; валидация обязана совпадать.
- **Auth:** без `MCPRIG_PASSWORD*` и без `MCPRIG_PROXY_SECRET` менеджер не
  стартует, кроме явного `MCPRIG_AUTH=off`.
- **Секреты:** в ребёнка только `$VAR` его серверов; `env.json` не наследуется.
- **Логи:** хвост файла, фильтр по точному имени сервера.

## Решено

1. «Вызов» — собственный счётчик в `invoke_command` (`internal/stats`), не
   разбор лога: лог набора не содержит клиента и не переживает рестарт.
2. Репозиторий — `frosty-ad-gt.cloudpub.ru/sintez/mcprig`, операции через `gt`.
   Путь модуля (`github.com/sintez/mcprig` не резолвится) — ещё открыт.
3. Формат конфига — только JSON (`servers.json`): это общий формат с lazy-mcp и
   родной формат секции `mcpServers` у клиентов, менять его ради TOML значило бы
   ломать копипаст из чужих README и тянуть парсер в бинарник без зависимостей.
4. Codemap из `lazy-mcp` удалён; для этого репозитория — когда код перестанет
   двигаться.

## Долг, принятый сознательно (2026-11-09)

Ревью паладина и арбитра по `4399e9e` закрыто правками; ниже — то, что
оставлено с открытыми глазами, с причиной:

Занятость явного порта закрыта в `674d792`: `POST /api/sets` теперь тоже
отвечает `409 «порт N занят процессом»`, а тесты реестра выбирают свободный
порт через `freePort(t)` вместо фиксированного `"port":9100`.

- **`caps.Logging`** в browse: поле deprecated в SDK (SEP-2577), исчезнет в
  следующей ревизии протокола — тогда убрать.
- **Очередь на scrypt при логине** не ограничена: лимит 5 неудач/мин стоит до
  проверки пароля, залп первых попыток встанет в очередь. Риск — только за
  прокси с большим трафиком.
- **`goreleaser check` не прогонялся:** инструмент требует Go 1.27.3, а загрузка
  тулчейна упирается в недоступный `sum.golang.org`. Структура `.goreleaser.yaml`
  проверена разбором YAML (v2, `./cmd/mcprig`, linux/darwin × amd64/arm64,
  архивы, checksums). Образы Docker не собирались — реестр недоступен.

Закрыто: холодный обход `${VAR}` (`4cad5cd`) — имена резолвятся параллельно,
до 8 сразу, порядок значений и текст `remoteError` прежние; первый
`GET /api/env`, старт набора, probe и browse больше не ждут 5 с на переменную.
