   `~/.local/share/opencode/log/opencode.log`.

## Грабли, на которые уже наступали

- **Рестарт панели внутри хода убивает собственный ответ.** Рестарт
  `openchamber.service` запускать только отдельным юнитом с паузой:
  `systemd-run --user --collect --unit=<имя> /bin/zsh <скрипт>`, в скрипте
  `sleep 15` перед `systemctl --user restart openchamber.service`.
- **Общий git-индекс.** Параллельные полосы стейджат в один `.git/index` и
  утаскивают чужое. Каждой полосе — приватный индекс:
  `export GIT_INDEX_FILE=$PWD/.git/index.<метка> && git read-tree HEAD && git add <свои файлы> && git commit -m "…" && rm -f .git/index.<метка>`.
  После полос — `git reset -q`, иначе в `git status` висят ложные `D`.
- **`rm -rf` и `docker rm` отбиваются политикой** (`Permission denied: shell`);
  `mv`, `docker stop`, `docker run --rm` разрешены.
- **Порты 9100–9199** делят наборы, тесты и чужие сервисы (на 9119 живёт
  `hermes`); `doctor` про такие порты предупреждает и выдача их пропускает.
- **`invoke_command`** принимает имя инструмента в поле `command_name`;
  `command` — ошибка «лишние ключи».
- Эталонный TS-менеджер на `127.0.0.1:9091` (pid 33084) не трогать.
