# Плагин opencode: MCP идут через mcprig

Небольшой плагин, который дописывает в system prompt одну постоянную строку:
MCP-серверы доступны через `mcprig`, вход — его мета-тулы.

В тексте названы **только** мета-тулы самого mcprig (`list_servers`,
`list_commands`, `describe_commands`, `invoke_command`). Серверы за прокси не
упомянуты, поэтому файл одинаков для любого набора и любого хоста и не
устаревает, когда набор правят.

## Установка

```bash
cp integrations/opencode/mcprig-route.ts ~/.config/opencode/plugins/
```

Затем перезапусти хост, который грузит плагины (инстанс OpenChamber или сессию
CLI): файл плагина читается при старте.

Проверка, что загрузился:

```bash
grep 'loading plugin.*mcprig-route' ~/.local/share/opencode/log/opencode.log
```

`opencode plugin list` здесь не проверка: он показывает сервер, к которому
подключён CLI, а это может быть другой процесс.

## Выключить

```bash
export MCPRIG_ROUTE=off
```

или удалить файл из каталога плагинов. Без mcprig подсказка безвредна, но
бесполезна — её лучше убрать, а не оставлять.

## Заметки

- Текст постоянный намеренно: он дописывается каждый шаг, а переменная часть
  меняла бы префикс запроса и обнуляла prompt cache.
- Хуков два — `context` и `compaction`: иначе правило пропадает ровно на том
  запросе, который переписывает контекст.
