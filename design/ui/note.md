# Панель mcprig — макет

Сделан в open-design (проект `mcprig-ui-fbb2`, run `b4e69c78-37ce-41d0-bee4-753d981b2f6e`),
проверен рендером в Chromium 1440 px. Макет, не код панели: разметка и CSS одним файлом,
без сборки и без внешних зависимостей.

| файл | что это |
| --- | --- |
| `index.html` | главный экран: топбар, рейл наборов, KPI, таблица наборов, таблица вызовов, правая колонка, статус-строка |
| `states.html` | три состояния: пусто, набор остановлен, плотная таблица 40 строк |
| `panel.png` | скриншот `index.html` при 1440×1000 |
| `states.png` | скриншот `states.html` |

Что взято в реализацию этапа 5:
- плотность: строки 28 px, табличные числа, 1 px границы, радиус 6, ноль теней и градиентов;
- структура правой колонки — серверы набора с транспортом и последней ошибкой, переменные с
  источником (`openbao`/`file`/`env`), хвост лога;
- статус-строка с версией, размером бинаря, RSS, uptime и версией протокола;
- ключ показывается только префиксом, полное значение — по кнопке «показать» (в движке: значение
  отдаётся один раз при создании ключа, потом только префикс).

Что макет не решает: реальные данные, поведение фильтров и сортировок, мобильная ширина.
