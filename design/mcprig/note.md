# mcprig — знак

**Решение 2026-11-08: рука, сжимающая три кабеля.** Гравюра, один цвет.

## Как пришли

Первая версия — «стенд в разрезе» (плита, две стойки, акцентная шапка) — забракована
владельцем: в 16 px читается как стол с прибором или как «Π». Вторая попытка, четыре
знака на тёмной плитке (патч-панель, джек, ферма, монограмма) и четыре от open-design —
отклонены все восемь: «слишком иконочно».

Жанр сменили по референсам, которые владелец назвал: **DietrichGebert/ponytail**
(гравюрный портрет персонажа, чёрное на белом) и **mnemosyne-oss/mnemosyne**
(1-bit гравюра + капсом имя). У обоих нет плитки, нет абстрактного глифа и нет
акцентного цвета: узнаваемость держится на рисунке с характером.

## Что лежит

| файл | что это |
| --- | --- |
| `logo-hand-light.png` | знак, чёрная тушь, прозрачный фон — для светлой темы |
| `logo-hand-dark.png` | тот же знак цветом `#E6EFF1` — для тёмной темы |
| `hand.svg` | вектор, обводка `currentColor`, tracem'ом из растра (potracer, opticurve) |
| `hook.svg` | отвергнутая альтернатива: крюк с узлом (сохранил как вариант для favicon-логики) |
| `favicon.svg` | упрощённый знак для 16 px: кулак и три пальца-кабеля, средний в акценте |
| `lockup-hand-dark.png` | знак + слово «mcprig» (DejaVu Sans Bold, черновой набор) |

`icon.svg` — прежний вариант, оставлен как история, не использовать.

Значащие альтернативы той же серии — `ink/{hook,winch,rigger}.png` (гравюры),
отвергнуты: крюк телесный, ворот не масштабируется, риггер требует дисциплины в
текстах и всё равно не работает в favicon.

## Палитра

Знак монохромный, акцент `#2BB3A3` остаётся только в интерфейсе. Токены — `design/tokens.css`.
