# mcprig — знак

**Решение 2026-11-08: рука, сжимающая три кабеля.** Гравюра, один цвет.

## Как пришли

Первая версия — «стенд в разрезе» (плита, две стойки, акцентная шапка) — забракована
владельцем: в 16 px читается как стол с прибором или как «Π». Вторая попытка, четыре
знака на тёмной плитке (патч-панель, джек, ферма, монограмма) и четыре от open-design —
отклонены все восемь: «слишком иконочно».

Жанр сменили по референсам, которые владелец назвал: **DietrichGebert/ponytail**
(гравюрный портрет персонажа, чёрное на белом) и **mnemosyne-oss/mnemosyne**
(1-bit гравюра + капсом имя). У обоих нет плитки, нет абстрактного глифа и нет
акцентного цвета: узнаваемость держится на рисунке с характером.

## Что лежит

| файл | что это |
| --- | --- |
| `logo-hand-light.png` | знак, `#0B2229` на прозрачном, 880×880 — для светлой темы |
| `logo-hand-dark.png` | тот же знак цветом `#E6EFF1`, 880×880 — для тёмной темы |
| `hand.svg` | вектор, обводка `currentColor`, tracem'ом из растра (potracer, opticurve); плита в нём — первый подобъект пути |
| `hand-mark.svg` | знак без плиты, `currentColor`: `hand.svg` минус первый подобъект, viewBox по габариту знака |
| `hook.svg` | отвергнутая альтернатива: крюк с узлом (сохранил как вариант для favicon-логики) |
| `favicon.svg` | упрощённый знак для 16 px: кулак и три пальца-кабеля, средний в акценте |
| `lockup-hand-dark.png` | знак + слово «mcprig» (DejaVu Sans Bold, черновой набор) |

`icon.svg` — прежний вариант, оставлен как история, не использовать.

Значащие альтернативы той же серии — `ink/{hook,winch,rigger}.png` (гравюры),
отвергнуты: крюк телесный, ворот не масштабируется, риггер требует дисциплины в
текстах и всё равно не работает в favicon.

## 2026-11-13: плиту убрали

`logo-hand-{light,dark}.png` до этой даты были плитами 1400×1400 (89 % пикселей —
сплошное поле, кулак вырезан прозрачностью): на белом README это чёрный квадрат, на
тёмной теме — светлая плашка, а к 220 px гравюра на костяшках сливалась. Теперь это
знак на прозрачном: та же геометрия, ни пикселя формы не тронуто.

Как получено: в `hand.svg` один path из 90 подобъектов — квадрат-плита и 89 штрихов
гравюры. Плита — подобъект №1, остальное в той же заливке nonzero даёт ровно то, что
было в дыре плиты (сверено с её альфой: расхождение 0,0 %). Поэтому `hand-mark.svg` —
исходный path без первого `M…Z`, обводка `currentColor`, viewBox `86.99 54.14 933.02 933.02`
(габарит знака 413×880 плюс 3 % поля). PNG сняты с него через cairosvg и перепакованы
в PNG-8: один цвет в палитре + 256 уровней альфы, 53 КБ на файл вместо 133 КБ у RGBA.

Плиты на месте: `archive/logo-hand-{light,dark}-plate.png` (1400×1400, как было).
